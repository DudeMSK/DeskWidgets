# DeskWidgets

Фоновое приложение для Windows 11: живёт в трее и рисует виджеты прямо на рабочем столе.
Первый виджет — **Яндекс Музыка** (обложка, трек, прогресс, пауза/следующий/предыдущий).

Стек: Electron (виджеты — обычные HTML/CSS/JS), Win32 через [koffi](https://koffi.dev) без компиляции.

## Запуск

```bash
npm install
npm start
```

Приложение появится иконкой в трее (если её не видно — раскройте «скрытые значки» у часов).
Левый или правый клик по иконке открывает меню:

| Пункт | Что делает |
|---|---|
| *Название виджета* → Показывать | включает и выключает виджет |
| *Название виджета* → Положение | слой окна: на рабочем столе / как обычное окно / поверх всех |
| *Название виджета* → Сбросить позицию | возвращает виджет в стартовое место |
| Переместить виджеты | режим перемещения: вокруг виджетов появляется пунктирная рамка, их можно таскать мышью; кнопки в этот момент не срабатывают |
| Запускать вместе с Windows | автозапуск |
| Папка с виджетами | `%APPDATA%\deskwidgets\widgets` — сюда кладутся свои виджеты |
| Перечитать виджеты | подхватывает новые виджеты и правки манифестов без перезапуска |

Настройки (включённые виджеты, слои, позиции) лежат в `%APPDATA%\deskwidgets\settings.json`.

## Сборка EXE

```bash
npm run dist
```

Результат в `dist/`:

* `DeskWidgets Setup 0.1.0.exe` — установщик (на пользователя, права администратора не нужны, ставится в
  `%LOCALAPPDATA%\Programs\DeskWidgets`, есть деинсталлятор; настройки при удалении сохраняются);
* `win-unpacked\DeskWidgets.exe` — то же приложение без установки: папку можно скопировать куда угодно.

Сборка не подписана сертификатом, поэтому SmartScreen при первом запуске покажет «Windows защитила ваш компьютер» —
«Подробнее» → «Выполнить в любом случае». Подпись настраивается в секции `build.win` файла `package.json`.
Первая сборка скачивает из интернета Electron и ресурсы electron-builder (около 150 МБ).
Собранное приложение и `npm start` используют одну папку настроек и один замок «единственный экземпляр»:
одновременно работать может только одно из них.

## Как устроены слои

* **desktop** (по умолчанию) — виджет лежит над обоями и значками, но под всеми окнами, и **остаётся на месте при
  «Показать рабочий стол» (Win+D)**. Технически это окно верхнего уровня, у которого владелец (owner) — окно
  рабочего стола `Progman` ([src/main/layer.js](src/main/layer.js)). Обычное окно, даже лежащее на самом дне
  Z-порядка, Win+D скрывает; окно с владельцем `Progman` — нет. Прозрачность и тень сохраняются.
  Вариант с `SetParent` (дочернее окно рабочего стола) тоже переживает Win+D, но не смешивает прозрачность с обоями:
  вокруг карточки остаётся тёмный прямоугольник.
* **normal** — как обычное окно.
* **top** — поверх всех окон.

Перетаскивание сделано самим приложением (pointer-события в [preload](src/main/preload.js) → IPC → `setBounds`),
а не через `-webkit-app-region`.

## Виджет Яндекс Музыки

Данные берутся из системных медиа-сессий Windows (SMTC, тот же источник, что у плашки громкости), поэтому
**вход в аккаунт и токены не нужны**. Помощник [native/smtc.ps1](native/smtc.ps1) (Windows PowerShell 5.1, ничего
ставить не надо) раз в секунду отдаёт состояние всех сессий построчным JSON и принимает команды управления.
Запускается, только пока включён хотя бы один виджет с правом `media`.

Работает с десктопным приложением (`ru.yandex.desktop.music`) и с веб-версией в браузере. Какую сессию показывать,
решает `config.sourceFilter` — регулярное выражение по идентификатору приложения (по умолчанию `yandex`).
Переопределить можно в `settings.json`:

```json
{ "widgets": { "yandex-music": { "config": { "sourceFilter": "chrome|msedge", "fallbackToAny": false } } } }
```

* `sourceFilter` — какие сессии считать «Яндекс Музыкой»; для веб-версии в Chrome/Edge подойдёт `chrome|msedge`.
* `fallbackToAny` — если подходящей сессии нет, показать любую играющую.

## Свой виджет

Папка в `widgets/` (встроенные) или в `%APPDATA%\deskwidgets\widgets` (свои), внутри `manifest.json` и страница.

```json
{
  "id": "my-widget",
  "name": "Мой виджет",
  "entry": "index.html",
  "enabledByDefault": true,
  "permissions": ["media"],
  "window": { "width": 300, "height": 120, "layer": "desktop", "anchor": "top-right" },
  "config": { "любые": "ваши настройки" }
}
```

* `id` — латиница, цифры, `-`, `_`.
* `window.anchor` — `top-right` (по умолчанию), `top-left`, `bottom-right`, `bottom-left`. Новые виджеты выстраиваются
  столбиком у выбранного угла.
* `window.focusable` — `true`, только если виджету нужен ввод с клавиатуры (по умолчанию окна не забирают фокус).
* `permissions` — сейчас только `media`.

Окно прозрачное и без рамки: рисуйте карточку с отступом ~8 px от краёв, чтобы поместилась тень.
Страница получает объект `window.deskwidgets`:

```js
const info = await deskwidgets.getInfo();   // { id, name, layer, locked, config }

const stop = deskwidgets.media.subscribe(({ current, sessions }) => {
  // session: { id, app, status, title, artist, album, pos, dur, thumb, canPrev, canNext, canPlayPause }
  // pos/dur — секунды, thumb — data: URL обложки или null
});
deskwidgets.media.control('playpause', sessionId); // 'play' | 'pause' | 'next' | 'prev'
```

Примеры: [widgets/clock](widgets/clock) (минимум) и [widgets/yandex-music](widgets/yandex-music).

## Диагностика

```bash
npm run probe
```

Печатает окна приложения: позицию, видимость, Z-порядок, стили и `ownerIsDesktop`. С ключом `-Shot out.png` сохраняет
снимок содержимого окна через `PrintWindow`. Учтите: Chromium не перерисовывает полностью перекрытые окна, поэтому у
закрытого виджета снимок может оказаться устаревшим.

## Известные ограничения и что дальше

* **Перезапуск Проводника** (`explorer.exe`) уничтожает `Progman`, и окна-владельцы виджетов вместе с ним. Пока
  нужно «Перечитать виджеты» из меню или перезапустить приложение. Стоит ловить `TaskbarCreated` и пересоздавать окна.
* Несколько мониторов и разный масштаб (DPI) не проверялись; позиции хранятся в DIP.
* SMTC опрашивается раз в секунду отдельным процессом PowerShell (~70–110 МБ). Если это станет проблемой —
  заменить на маленький нативный помощник (C#/Rust) с событиями вместо опроса.
* Нет окна настроек: параметры виджетов правятся в `settings.json`.
* Установщик собирается, но на практике проверялась только распакованная версия (`win-unpacked\DeskWidgets.exe`):
  запуск, слой «рабочий стол», помощник SMTC. Сам установщик, автообновления и подпись кода не тестировались.
* Если `npm start` пишет `fetch failed` при скачивании Electron, а доступ в сеть идёт через прокси: Node по умолчанию
  игнорирует `HTTPS_PROXY`, запустите с `NODE_USE_ENV_PROXY=1`.
